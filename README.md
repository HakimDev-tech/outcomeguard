# OutcomeGuard

> Know if a resource can actually get you to your goal.

Evidence-backed AI engine that evaluates whether a resource is sufficient to achieve a specific goal, identifies missing requirements, and provides actionable recommendations.

## Status
Hackathon MVP — architecture scaffold.

## Core flow
Goal → Requirements → Resource → Evidence → Coverage → Verdict → Recommendation

## Tech Stack
Next.js · TypeScript · PostgreSQL · Supabase · RAG · LLM API · Tailwind CSS
